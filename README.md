# Project Akhir Data Science

A base framework for building Streamlit applications.

## Installation

Install the required packages:

```bash
pip install -r requirements.txt
```

## Running the App

To run the Streamlit application:

```bash
streamlit run app.py
```

The app will open in your default browser at `http://localhost:8501`

## Project Structure

- `app.py` - Main application file
- `requirements.txt` - Python dependencies
- `.streamlit/config.toml` - Streamlit configuration
- `README.md` - This file

## Features

- Multi-page navigation with sidebar
- Metrics display
- File upload capability
- Data visualization examples
- Configurable settings page

## Customization

Edit `app.py` to add your own pages and functionality. Modify `.streamlit/config.toml` to customize the theme and server settings.
